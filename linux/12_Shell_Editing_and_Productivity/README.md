# Shell Editing & Productivity

Terminal editing and practical shell habits for creating scripts and configuration files.

## Architecture

Terminal → Editor → File → Save/Exit

## Commands

`nano`

## Core Concepts

nano is a simple terminal editor for scripts and configuration. Ctrl+O saves, Ctrl+X exits, and Ctrl+W searches. Productivity comes from combining commands, using documentation, reusing history, and creating appropriate aliases.
