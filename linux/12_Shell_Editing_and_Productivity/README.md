# Shell Editing & Productivity

Use a terminal editor and develop efficient command-line habits for scripts and configuration.

## Architecture

Terminal → Editor → File → Save → Exit

## Commands & Syntax

nano

## Core Concepts

nano is a simple terminal editor useful for scripts and configuration. Ctrl+O saves, Ctrl+X exits, and Ctrl+W searches. Productivity comes from combining commands, using history, documentation, tab completion, and appropriate aliases.
