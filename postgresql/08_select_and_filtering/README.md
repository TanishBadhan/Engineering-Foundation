# SELECT and Filtering

## What It Is
SELECT retrieves required columns and rows using predicates, ordering, and limits.

## Why It Matters
These patterns are fundamental to reliable backend database work and query reasoning.

## Key Concepts
Understand syntax, execution behavior, data integrity, NULL behavior, and intended row grain.

## Common Mistakes
Verify target rows and query results; do not apply changes mechanically.

## Practice
See `practice.sql` for progressive exercises.

## Engineering Notes
Prefer explicit, predictable SQL and database-enforced invariants.
