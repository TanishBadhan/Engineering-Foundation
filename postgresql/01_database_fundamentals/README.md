# Database Fundamentals

## What It Is
databases, schemas, tables, rows, columns, keys, relationships, and integrity.

## Why It Matters
This is required for reliable backend database work, query reasoning, and technical interviews.

## Key Concepts
Understand syntax, execution behavior, data integrity implications, and common failure modes.

## Common Mistakes
Do not apply syntax mechanically. Verify row grain, NULL behavior, constraints, transaction boundaries, and intended target rows.

## Practice
The exercises in `practice.sql` move from direct syntax to combinations with earlier topics.

## Engineering Notes
Prefer clear, explicit SQL and understand the tradeoffs before introducing abstraction.
