# ALTER TABLE

## What It Is
ALTER TABLE evolves an existing schema through columns, names, types, and constraints.

## Why It Matters
These patterns are fundamental to relational backend applications.

## Key Concepts
Understand relationship cardinality, join predicates, row grain, and unmatched rows.

## Common Mistakes
Watch for accidental Cartesian products, wrong join keys, and unintended row multiplication.

## Practice
See `practice.sql` for progressive exercises.

## Engineering Notes
Always identify the expected result grain before joining relations.
