# Triggers

## What It Is
Triggers automatically execute a trigger function for specified INSERT, UPDATE, or DELETE events.

## Why It Matters
These features support reusable database operations and controlled automation close to stored data.

## Key Concepts
Understand parameters, invocation, trigger timing, NEW and OLD records, and side effects.

## Common Mistakes
Do not confuse procedures with functions or hide excessive business logic in triggers.

## Practice
See `practice.sql` for progressive exercises.

## Engineering Notes
Use database-side automation selectively and make implicit behavior easy to understand.
