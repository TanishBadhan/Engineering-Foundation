# PostgreSQL

A structured PostgreSQL learning path covering relational database fundamentals, SQL querying, transactions, advanced SQL, database programming, and automation.

## Learning Roadmap

### Foundations
01. Database Fundamentals
02. SQL Command Categories
03. PostgreSQL CLI

### Database Structure
04. Database & Table Creation
05. Data Types
06. Constraints

### Data Manipulation & Querying
07. INSERT / UPDATE / DELETE
08. SELECT & Filtering
09. Aggregate Functions
10. GROUP BY & HAVING
11. String Functions

### Schema & Relational Modeling
12. ALTER TABLE
13. Relationships & Foreign Keys
14. JOINs

### Query Expressions
15. CASE & COALESCE

### Transactions
16. Transactions & TCL

### Reusable & Advanced Queries
17. Views
18. CTEs
19. Window Functions

### Database Programming
20. User-Defined Functions
21. Stored Procedures
22. Triggers

## Practice Database

The examples use a shared practice database defined in `00_setup/schema.sql` and populated by `00_setup/seed.sql`.

## Learning Goal

Build strong PostgreSQL and SQL skills for backend engineering, data-intensive applications, production systems, and technical interviews.
