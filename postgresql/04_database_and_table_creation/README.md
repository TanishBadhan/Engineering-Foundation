# database and table creation

## What It Is
CREATE DATABASE and CREATE TABLE define database structures.

## Why It Matters
This is required for reliable backend database work and query reasoning.

## Key Concepts
Understand syntax, execution behavior, data integrity, and type semantics.

## Common Mistakes
Do not apply syntax mechanically; verify object names, constraints, and expected results.

## Practice
See `practice.sql` for progressive exercises.

## Engineering Notes
Prefer explicit schema definitions and types that match the data's meaning.
