# String Functions

## What It Is
String functions transform and inspect text values.

## Why It Matters
This is required for backend database work, analytics, and maintainable schemas.

## Key Concepts
Understand row grain, NULL behavior, execution order, and how the operation changes or summarizes data.

## Common Mistakes
Do not confuse row filtering with group filtering or mutate schemas without considering existing data.

## Practice
See `practice.sql` for progressive exercises.

## Engineering Notes
Prefer clear, explicit SQL and verify the resulting row set or schema.
